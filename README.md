# Git Practice Project

A small sandbox for practicing Git commands.

## Suggested exercises
1. `git status` / `git add` / `git commit` — stage and commit these files.
2. Edit `src/calculator.py`, then `git diff` and commit again.
3. Create a branch (`git checkout -b feature/greeting`), edit `src/greet.py`, merge it back.
4. Change the same line of `docs/notes.md` on two branches to create a merge conflict.
5. Use `git log --oneline --graph` to inspect history.
6. Try `git stash`, `git restore`, `git reset`, and `git revert`.
